## Description
Create the player equipment slot structure so weapons, armor, and accessories can be assigned to defined slots in a consistent way.

## Tasks (optional)
- [ ] Define equipment slot types
- [ ] Create player equipment container
- [ ] Map slots to item categories
- [ ] Expose slot state for debugging

## Acceptance Criteria
- [ ] The player has weapon, armor, and accessory slots
- [ ] Each slot is clearly associated with a valid item category
- [ ] Slot state can be read by other gameplay systems
- [ ] The slot structure is easy to extend later if needed
