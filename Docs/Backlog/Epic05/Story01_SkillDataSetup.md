## Description
Create the skill data structure so each skill can define its cooldown, effect type, and core values in a reusable and tunable way.

## Tasks (optional)
- [ ] Create skill data model
- [ ] Define skill effect types
- [ ] Add cooldown and value fields
- [ ] Expose values for balancing

## Acceptance Criteria
- [ ] Skills can store cooldown and effect information
- [ ] Different skill types can share the same data structure
- [ ] Skill values can be configured without hardcoding behavior
- [ ] Skill data is easy to tune during development
