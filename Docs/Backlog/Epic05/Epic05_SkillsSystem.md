## Overview
Implement the skills system for Forsaken. This epic establishes skill definitions, manual activation, cooldown handling, auto skill behavior, and skill effect resolution so combat has active player interaction and scalable combat depth.

## Scope
Included:
- Skill data setup
- Manual skill activation
- Cooldown handling
- Auto skill toggle behavior
- Skill effect resolution

Excluded:
- Skill tree progression
- Skill upgrade UI polish
- Premium skill unlocks
- Advanced combo systems
- Cosmetic-only skill visuals

## Acceptance Criteria
- [ ] Skills can be defined through reusable data or configuration
- [ ] The player can activate skills manually during combat
- [ ] Skills respect cooldown timing before they can be reused
- [ ] Auto skill behavior can trigger eligible skills automatically
- [ ] Skill effects apply correctly to combat outcomes
- [ ] The skills system is reusable and easy to extend later
