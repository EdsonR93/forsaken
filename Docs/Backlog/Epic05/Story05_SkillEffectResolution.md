## Description
Resolve skill effects in combat so activated skills can apply damage, buffs, or other supported effects correctly.

## Tasks (optional)
- [ ] Map skills to effect resolution
- [ ] Apply supported combat effects
- [ ] Connect effects to combat targets or player state
- [ ] Expose effect results for debugging

## Acceptance Criteria
- [ ] Activated skills can resolve into valid gameplay effects
- [ ] Supported effects apply correctly to player or enemy state
- [ ] Skill outcomes integrate with the combat system safely
- [ ] Effect resolution can be tested and debugged during development
