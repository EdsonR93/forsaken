## Overview
Implement the economy and upgrade systems for Forsaken. This epic establishes run currency, gold rewards, upgrade definitions, purchase flow, and upgrade value application so players can grow stronger during a run.

## Scope
Included:
- Currency model setup
- Gold reward flow
- Run upgrade definitions
- Upgrade purchase flow
- Upgrade value application

Excluded:
- Prestige currency
- Offline earnings
- Premium currency purchases
- Shop UI polish
- Advanced economy balancing

## Acceptance Criteria
- [ ] The game supports the core run currency model
- [ ] Defeated enemies can reward gold correctly
- [ ] Run upgrades can be defined through reusable data
- [ ] Players can purchase upgrades when they have enough currency
- [ ] Purchased upgrades modify the intended gameplay values
- [ ] The economy flow is reusable and easy to balance
