## Overview
Implement the ads and monetization systems for Forsaken. This epic establishes rewarded ad flow, ad removal purchase support, premium currency setup, cosmetic monetization hooks, and validation flow so the game can support fair monetization.

## Scope
Included:
- Rewarded ad flow
- Ad removal purchase setup
- Premium currency setup
- Cosmetic reward hooks
- Monetization validation flow

Excluded:
- Live ops events
- Battle pass systems
- Subscription features
- Advanced offer bundles
- Store art polish

## Acceptance Criteria
- [ ] Rewarded ads can grant the intended gameplay rewards safely
- [ ] The game supports an ad removal purchase state
- [ ] Premium currency can be stored and consumed safely
- [ ] Cosmetic reward hooks exist for future monetized cosmetics
- [ ] Monetization actions validate success before granting rewards
- [ ] The monetization flow is reusable and testable
