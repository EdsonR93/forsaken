## Overview
Implement the enemy system for Forsaken. This epic establishes enemy spawning, movement, health setup, boss encounters, and stage scaling so combat has valid targets and progression pressure.

## Scope
Included:
- Basic enemy data and setup
- Enemy spawning flow
- Enemy lane movement
- Boss enemy setup
- Stage-based stat scaling

Excluded:
- Loot drops
- Equipment rewards
- Skills
- Prestige and economy systems
- UI polish and enemy VFX polish

## Acceptance Criteria
- [ ] Enemies can spawn into the active lane correctly
- [ ] Enemies move toward the player in a predictable way
- [ ] Enemies have health and damage values that can scale by stage
- [ ] Boss enemies can appear on defined stage intervals
- [ ] Boss enemies have stronger stats than normal enemies
- [ ] Enemy defeat integrates with the combat flow from Epic 1
