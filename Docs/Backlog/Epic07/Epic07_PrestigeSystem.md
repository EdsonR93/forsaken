## Overview
Implement the prestige system for Forsaken. This epic establishes prestige currency, reward calculation, reset behavior, and permanent upgrades so players can restart progress with stronger long term growth.

## Scope
Included:
- Prestige currency setup
- Prestige reward calculation
- Prestige reset flow
- Permanent upgrade definitions
- Permanent upgrade application

Excluded:
- Offline earnings
- Premium currency
- Shop UI polish
- Advanced prestige layers
- Prestige visual effects polish

## Acceptance Criteria
- [ ] The game supports a permanent prestige currency
- [ ] Prestige rewards can be calculated from player progress
- [ ] A prestige reset can clear run progress safely
- [ ] Permanent upgrades can be defined through reusable data
- [ ] Purchased permanent upgrades modify intended values correctly
- [ ] The prestige flow is reusable and easy to balance
