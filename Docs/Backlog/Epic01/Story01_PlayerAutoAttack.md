## Description
Implement the automatic attack cycle for the player so attacks trigger repeatedly without manual input and always attempt to hit the current valid target.

- [ ] A combat script controls the player auto attack loop

- [ ] The player can detect a valid target before attacking
- [ ] A successful attack sends damage to the target enemy
