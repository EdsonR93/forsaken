## Overview
Implement the loot system for Forsaken. This epic establishes item drop rules, rarity selection, boss drop improvements, and item merging so combat rewards the player with meaningful progression.

## Scope
Included:
- Loot table setup
- Enemy equipment drops
- Boss-specific drop improvements
- Item rarity selection
- Merge system for upgrading items

Excluded:
- Equipment stat application
- Inventory UI polish
- Named legendary unique effects behavior
- Premium currency rewards
- Prestige rewards

## Acceptance Criteria
- [ ] Enemies can drop items through a reusable loot flow
- [ ] Loot rarity can be selected from defined drop rules
- [ ] Bosses provide stronger or more valuable loot outcomes
- [ ] Item drops support the planned equipment categories
- [ ] Players can merge matching items into a higher rarity result
- [ ] The loot flow is reusable and easy to balance
