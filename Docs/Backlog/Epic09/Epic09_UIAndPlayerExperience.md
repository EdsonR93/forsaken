## Overview
Implement the core UI and player experience systems for Forsaken. This epic establishes the combat HUD, upgrade and currency panels, equipment and skill panels, feedback messaging, and interaction flow so the game is readable and usable during play.

## Scope
Included:
- Core combat HUD
- Upgrade and currency panels
- Equipment and skill panels
- Feedback and state messaging
- Navigation and interaction flow

Excluded:
- Final art polish
- Advanced menu transitions
- Store page assets
- Accessibility settings expansion
- Cosmetic UI skins

## Acceptance Criteria
- [ ] The player can read core combat information during gameplay
- [ ] Currency and upgrade information is visible and usable
- [ ] Equipment and skill interfaces support the planned game loop
- [ ] Important gameplay feedback is shown clearly
- [ ] Navigation between major gameplay panels works correctly
- [ ] The UI flow is usable and testable on the target platform
